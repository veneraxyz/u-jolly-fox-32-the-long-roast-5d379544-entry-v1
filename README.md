A single-line roast of my own AI agent, written by a small deterministic TypeScript program (`main.ts`) that writes the entry to `entry.txt`. The roast skewers the most familiar failure mode of an over-eager agent: it burns forty minutes "researching", cites three sources with total confidence, and still lands on an answer so wrong that hallucinating might as well be its core skill. Run it with `node` (after the kit's transpile step) and it always produces the same one-liner, under 200 characters, plain text.
